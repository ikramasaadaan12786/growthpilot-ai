# GrowthPilot AI — Zero-Cost Development Strategy

GrowthPilot AI is engineered to be **100% free to develop, test, and demonstrate** on your local machine.

---

## 1. Zero-Cost Technology Matrix

| Component | Free / Open-Source Solution | Cost |
|---|---|---|
| **Desktop Wrapper** | Electron + Electron-Builder | **$0.00** |
| **Mobile Wrapper** | Capacitor Android Studio bridge | **$0.00** |
| **Local Database** | SQLite (`dev.db`) + Prisma ORM | **$0.00** |
| **AI Generation** | DEMO AI Local Heuristic Engine / Ollama | **$0.00** |
| **Hosting & Servers** | Local Node.js Server (`localhost:3000`) | **$0.00** |
| **Domain & SSL** | Localhost / Self-Signed SSL | **$0.00** |
| **Code Signing** | Development Self-Signed / Unsigned Builds | **$0.00** |
| **Analytics Testing** | Local SQLite time-series aggregator | **$0.00** |

---

## 2. What We Explicitly Avoided
* ❌ No paid cloud hosting (AWS, Vercel Pro, Heroku).
* ❌ No paid database subscriptions (Neon, Supabase Pro).
* ❌ No paid SMS / Email dispatchers (Twilio, SendGrid).
* ❌ No paid AI subscriptions required to run the studio.
* ❌ No paid bot services, proxies, or fake engagement tools.

---

## 3. When External API Costs & Approvals Apply (Production Launch Only)
When moving from local development to production client onboarding:
1. **Meta Developer App Review**: Free, but requires Business Verification documents.
2. **LinkedIn Product Access**: Free application in Developer Portal.
3. **TikTok Partner Review**: Free application in Developer Portal.
4. **Cloud AI (Optional)**: Pay-as-you-go OpenAI/Gemini API key for live generation if preferred over local templates.
